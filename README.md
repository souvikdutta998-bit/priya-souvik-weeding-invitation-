# Priya & Souvik — Wedding Invitation

Mobile-first scrolling wedding invitation with scratch-to-reveal date card and a password-protected blessings page at `/admin`.

## Required environment variables
- `ADMIN_PASSWORD`: private password for the couple's `/admin` page.
- `SESSION_SECRET`: long random secret used to sign admin sessions.
- `SUPABASE_URL`: Supabase project URL.
- `SUPABASE_SERVICE_ROLE_KEY`: Supabase service-role key. Keep private; never put it in browser code or GitHub.

## Supabase table
Run the SQL below in Supabase SQL Editor:

```sql
create table if not exists public.blessings (
  id bigint generated by default as identity primary key,
  name text not null,
  message text not null check (char_length(message) between 1 and 500),
  created_at timestamptz not null default now()
);
alter table public.blessings enable row level security;
```

The server uses the service-role key only on the server. Never expose it in `public/` files or commit it to GitHub.

## Render
Build command: `npm install`
Start command: `npm start`
Node version: 20 or newer.

Set all four environment variables in Render's Environment settings. The Supabase project stores blessings, so a Render persistent disk is not required.
